# Órbita — atualizações

Área de distribuição do aplicativo pessoal Órbita para Android.

[Baixar Órbita 1.0.8](https://github.com/leandronegociosdigitais-boop/orbita-atualizacoes/releases/download/v1.0.8/Orbita-1.0.8.apk)

Instale por cima da versão anterior, sem desinstalar. Depois use **Ajustes → Atualizações** no aplicativo.

Este repositório contém apenas arquivos de distribuição compilados e o canal de atualização assinado. Não contém lembretes, backups, credenciais ou o projeto original.

As atualizações das telas são aplicadas pelo próprio aplicativo. Atualizações de componentes Android exigem a confirmação do instalador do celular.
